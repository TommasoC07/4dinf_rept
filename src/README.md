# Gara Corsa Cavalli
Questa semplice applicazione simula una gara di cavalli
utilizzando i thread.
## Installazione
* Clona la repository
* Installa le dipendenze
* Avvia l'applicazione
## Come usare
* Fornire il percorso del file in cui verrà scritto lo svolgimento della gara e il vincitore.
* Inserire lunghezza gara (giri)
* Inserire dati cavallo (lentezza, nome)
* Al termine dell'inserimento del cavallo inserire "1" per aggiungere un altro cavallo,
  altrimenti per iniziare la gara inserire un altro numero
* Inizia la gara e verrà scritto il nome del vincitore
## Imprevisti e lentezza
La lentezza influirà sull'esito della gara perché andrà a modificare lo sleep dei thread, ma il
cavallo più veloce potrebbe non essere il cavallo vincente, infatti (in modo casuale) un
